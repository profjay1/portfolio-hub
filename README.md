# Portfolio Hub

> A production-style portfolio platform: public project showcase, resume download, recruiter contact form, and a protected admin dashboard. The repository is the demonstration: architecture decisions, tests, security, CI/CD, infrastructure as code, and operations are all in the open.

**Status:** under construction (see [roadmap](docs/roadmap.md)).
**Live:** _coming with v0.1.0_

## What is inside
| Area | Choices |
|---|---|
| Backend | Java 21, Spring Boot 4.1, Spring Modulith 2.1, Spring Security 7, PostgreSQL, Flyway |
| Frontend | Angular 22, Signals, Signal Forms, Vitest, Playwright |
| Delivery | GitHub Actions, protected `main`, Conventional Commits, semantic releases |
| Operations | Docker, Caddy (HTTPS), Ansible, encrypted backups with rehearsed restores, health checks and metrics |
| Documentation | ADRs, C4 diagrams, runbooks, OpenAPI |
